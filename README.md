# SNL GAMING v7.0

Фирменная прошивка для ESP32 с OLED-дисплеем 128×64 (SSD1306, I2C).  
8 игр, виртуальный питомец, приложения, система уровней и EEPROM-сохранения.

## 🎮 Игры

| Игра | Управление |
|------|------------|
| Snake | стрелки |
| Pong | UP / DOWN |
| Racer (гонки) | LEFT / RIGHT |
| Dino | UP (прыжок), DOWN (присесть) |
| Flappy Bird | UP или SELECT |
| Arkanoid | LEFT / RIGHT |
| Tanks | стрелки + SELECT (огонь) |
| Shooter | LEFT / RIGHT (движение), SELECT (огонь) |

## 🐾 Виртуальный питомец

- **Эмоции:** HAPPY / SAD / NORMAL (от уровня голода)
- **Уровень:** повышается каждые 100 очков (сохраняется в EEPROM)
- **Прогресс-бар:** `XX/100` + полоска
- **Кормление:** игра «Лови сердечки» (питомец двигается ← →)

## 📱 Приложения

- Секундомер
- Фонарик (белый экран)
- Калькулятор
- Генератор случайных чисел

## ⚙️ Настройки

- Смена темы: DARK / WHITE (сохраняется)
- Таблица рекордов
- Просмотр кода
- О прошивке

## 🔧 Управление

| Кнопка | Действие |
|--------|----------|
| UP / DOWN | навигация по меню |
| LEFT / RIGHT | навигация / управление в играх |
| SELECT | выбор / огонь / старт |
| BACK | назад / выход из игры |

## 💾 EEPROM (сохранения)

| Адрес | Данные |
|-------|--------|
| 0 | Snake рекорд |
| 1 | Pong рекорд |
| 2 | Racer рекорд |
| 3 | Dino рекорд |
| 4 | Shooter рекорд |
| 5 | Тема (0/1) |
| 6 | Flappy рекорд |
| 7 | Arkanoid рекорд |
| 8 | Tanks рекорд |
| 12 | Питомец: голод |
| 13 | Питомец: настроение |
| 14 | Питомец: счёт |
| 15 | Питомец: уровень |

## 📦 Требования

- **Плата:** ESP32 (NodeMCU-32S, WROOM, WROVER)
- **Дисплей:** OLED 128×64, I2C (SDA=21, SCL=22)
- **Кнопки:** 6 штук (GPIO 27,26,25,14,32,33) с подтяжкой к GND
- **Библиотеки:**
  - Adafruit GFX
  - Adafruit SSD1306
  - EEPROM (встроенная)

## 🖼️ Пользовательские битмапы

Размеры битмапов для питомца:

| Эмоция | Размер (главное меню) | Размер (меню питомца) |
|--------|----------------------|----------------------|
| NORMAL | 24×24 | 64×24 |
| HAPPY  | 24×24 | 64×24 |
| SAD    | 24×24 | 64×24 |

Битмапы хранятся в PROGMEM.

## 🚀 Установка

1. Установи библиотеки через Library Manager:
   - `Adafruit GFX Library`
   - `Adafruit SSD1306`
2. Открой `snlfrimmer.ino` в Arduino IDE
3. Выбери плату: **ESP32 Dev Module**
4. Настрой порт и загрузи прошивку
