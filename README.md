## 🖥️ Аппаратные требования

| Компонент | Параметры |
|-----------|-----------|
| **Микроконтроллер** | ESP32 (любая версия) |
| **Дисплей** | OLED 128x64, SSD1306, I2C |
| **Кнопки** | 6 кнопок (UP, DOWN, LEFT, RIGHT, SELECT, BACK) |
| **Питание** | 3.3V / 5V |

---

## 🔌 Подключение

| Компонент | ESP32 Pin |
|-----------|-----------|
| OLED SDA | GPIO 21 |
| OLED SCL | GPIO 22 |
| Кнопка UP | GPIO 27 |
| Кнопка DOWN | GPIO 26 |
| Кнопка SELECT | GPIO 25 |
| Кнопка BACK | GPIO 14 |
| Кнопка LEFT | GPIO 32 |
| Кнопка RIGHT | GPIO 33 |

> 💡 Все кнопки подключаются с использованием внутреннего подтягивающего резистора (INPUT_PULLUP)

## 📥 Установка

### 1. Установка библиотек (Arduino IDE)

```

Adafruit GFX Library
Adafruit SSD1306
Wire (встроенная)
EEPROM (встроенная)

```

### 2. Загрузка прошивки

```bash
git clone https://github.com/Sonly251/snl-gaming-firmware.git
cd snl-gaming-firmware
```

Откройте snl_gaming.ino в Arduino IDE, выберите плату ESP32 Dev Module и нажмите Upload.

🐾 Виртуальный питомец (Minigotchi)

Маленький друг, который живёт на главном экране!

Параметр Описание
Голод Уменьшается со временем. Нужно кормить!
Настроение Зависит от уровня голода
Счёт Растёт при игре в мини-игры и кормлении

Режимы питомца:

· 😐 Нормальный (>-<)
· 😊 Счастливый (>-<) — сытый
· 😢 Грустный (._.) — голодный

Игра с питомцем:

· В меню питомца нажмите SELECT, чтобы начать игру
· Ловите падающие сердечки корзиной
· Каждое пойманное сердечко повышает сытость и счёт
