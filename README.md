**Многофункциональная прошивка для ESP32 с OLED дисплеем (128x64) на базе SSD1306.**

Включает в себя 8 игр, полезные приложения, виртуального питомца и многое другое!

## ✨ Возможности

| Категория | Содержание |
|-----------|------------|
| 🎮 Игры | Snake, Pong, Racer, Dino, Shooter, Flappy Bird, Arkanoid, Tanks |
| 📱 Приложения | Секундомер, Фонарик, Калькулятор, Генератор случайных чисел |
| 🐾 Виртуальный питомец | Minigotchi — корми, играй, следи за настроением |
| ⚙️ Настройки | Рекорды, Светлая/Тёмная тема, Просмотр кода, О проекте |
| 💾 EEPROM | Сохранение рекордов, темы, данных питомца |

---

## 🖥️ Аппаратные требования

| Компонент | Параметры |
|-----------|-----------|
| **Микроконтроллер** | ESP32 (любая версия) |
| **Дисплей** | OLED 128x64, SSD1306, I2C |
| **Кнопки** | 6 кнопок (UP, DOWN, LEFT, RIGHT, SELECT, BACK) |
| **Питание** | 3.3V / 5V |

---

## 🔌 Подключение

| Компонент | ESP32 Pin |
|-----------|-----------|
| OLED SDA | GPIO 21 |
| OLED SCL | GPIO 22 |
| Кнопка UP | GPIO 27 |
| Кнопка DOWN | GPIO 26 |
| Кнопка SELECT | GPIO 25 |
| Кнопка BACK | GPIO 14 |
| Кнопка LEFT | GPIO 32 |
| Кнопка RIGHT | GPIO 33 |

> 💡 Все кнопки подключаются с использованием внутреннего подтягивающего резистора (INPUT_PULLUP)
