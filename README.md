# 🎮 SNL GAMING v7.0

**Фирменная прошивка для ESP32 на OLED 128x64**

---

## 📟 Характеристики

| Параметр | Значение |
|----------|----------|
| Платформа | ESP32 (WROOM / S3) |
| Дисплей | OLED 128×64 (I²C) |
| Управление | 6 кнопок (UP/DOWN/LEFT/RIGHT/SELECT/BACK) |
| Хранение | EEPROM 64 байта (рекорды, настройки) |

---

## 🕹️ Игры (8 штук)

| Игра | Управление |
|------|------------|
| Snake | стрелки, SELECT — выход |
| Pong | UP/DOWN, SELECT — выход |
| Racer | LEFT/RIGHT, SELECT — выход |
| Dino | UP — прыжок, DOWN — присесть, SELECT — выход |
| Flappy Bird | UP/SELECT — взмах |
| Arkanoid | LEFT/RIGHT, SELECT — выход |
| Tanks | стрелки + SELECT — выстрел |
| Shooter | LEFT/RIGHT + SELECT — стрельба |

---

## 🐾 Виртуальный питомец

- **Голод** (0–100) — уменьшается каждую минуту
- **Настроение** — зависит от голода
- **Уровень** — повышается каждые 100 очков
- **Прогресс-бар** — до следующего уровня
- **Кормление** — мини-игра «Лови сердечки»

---

## 📱 Приложения (APPS)

| Приложение | Описание |
|------------|----------|
| Stopwatch | Секундомер с миллисекундами |
| Flashlight | Белый экран |
| Calculator | Калькулятор (+ - * /) |
| Random Gen | Генератор случайных чисел |

---

## ⚙️ Настройки (SETTINGS)

| Пункт | Функция |
|-------|---------|
| Records | Таблица рекордов по 8 играм |
| Theme | Светлая / Тёмная тема |
| Code | Просмотр кода прошивки |
| About | Информация о версии |

---

## 🧠 Загрузчик (BIOS)

- **POST** — самодиагностика при включении
- **Boot Menu** — зажать SELECT при старте
- **Safe Mode** — отключение всех игр

---

## 🔧 Установка

### Требования
- Arduino IDE / PlatformIO
- Библиотеки: `Adafruit GFX`, `Adafruit SSD1306`, `EEPROM`

### Плата
```

ESP32 Dev Module
Flash: 4MB
Partition: Default

```

### Пины
```

I²C: SDA=21, SCL=22
Кнопки: 27,26,25,14,32,33

```

### Прошивка
1. Скачай `snl_gaming_v7.0.ino`
2. Установи библиотеки
3. Выбери плату ESP32
4. Залей прошивку
